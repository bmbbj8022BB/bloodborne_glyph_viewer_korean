블러드본 혈정석 세팅 뷰어

출처: bloodborne-wiki.com "Best Blood Gems Setups" (패치 1.08 기준) · 명칭은 블러드본 사전 기준 · 문양 코드를 누르면 복사돼요 · F/R/C 표기는 생략

용어 설명• 쇠약형(Waning, 결손형): 초승달 모양 소켓
• 리게인(Rally): 피격으로 잃은 HP(주황 게이지)를 공격으로 회복하는 시스템
• 리게인 혈정석: 그 회복량 증가

출처: bloodborne-wiki.com "Damage Calculation" (Sel의 Hunter's Guide to Damage + Kanaris 카운터 연구) · PvE 기준 · 일부는 커뮤니티 실측값

① 기본 흐름

총 공격력(AR) × 모션 배율(Dmg x) = 총 피해
총 피해 → 적 방어 적용(⑤ 곡선) = 실제 피해
※ 피해 타입별로 따로 계산한 뒤 합산

② 공격력(AR) 공식

AR = [기본 + (기본 × 보정 × 포화도)] × 혈정석% + 고정 공격력
항목의미
기본무기 기본 공격력 (+10 기준, 아래 ⑩ 표)
보정스탯 보정 계수. 중격/예리/온기/냉기 혈정석은 계수에 가산 (예: +65 → +0.65)
포화도스탯 수치별 비율 0~1 (⑥ 표). 소프트캡 25 / 50
혈정석 %곱연산 (합연산 아님)
고정 공격력마지막에 더함. 모션 배율은 고정분을 뺀 AR에 적용됨
고정 vs % 선택
  • 배율 높은 공격(코스의 기생충 기본기, 말뚝박이 차지 R2) → % 혈정석 유리
  • 배율 낮은 다단히트(변형 로가리우스 R1, 코스의 기생충 L2) → 고정 공격력 혈정석 유리

③ 피해 타입

구분내용
5대 타입물리 · 혈질 · 신비 · 화염 · 번개 (적 방어는 물리/타격/찌르기/혈질/신비/화염/번개 7종)
물리 하위일반 / 타격 / 찌르기. 공격 하나하나마다 타입이 다름
물리 공격력 상승일반 + 타격 + 찌르기 전부 적용
타격 / 찌르기 상승해당 타입 공격에만 적용 (특화 혈정석)
복합 타입한 공격이 물리+신비처럼 섞일 수 있음. 각 부분이 자기 방어로 감소
혈질 무기치카게·출혈검·시몬의 궁검는 변형 시 혈질 피해. 상태창 AR엔 물리만 표시

④ 혈정석 규칙

  • 곱연산: 27.2% 3개 = 1.272³ = 2.06배 (+106%). 합연산(+82%)이 아니야
  • 모두강화의(Nourishing): 무기의 모든 공격력 타입에 적용
  • 속성 변환: 순수 물리 무기에 신비/화염/번개 혈정석 → 기본 물리가 0이 되고 속성으로 변환, 신비 스탯 보정을 따름
  • 변환 우선순위: 신비 > 화염 > 번개 (화염+번개 같이 끼면 화염으로 변환, 번개 피해 0)
  • 변환된 무기는 Fire/Bolt Paper 사용 불가, Beast Blood Pellet도 속성엔 효과 없음
  • 변환 불가 무기(복합 무기·혈질 무기)는 자기가 가진 속성에만 % 적용, 없는 속성은 고정 공격력만 들어감
  • 고정 공격력 아이템: 발화 부싯깃(화염 +80), Bolt Paper(번개 +80), Empty Phantasm Shell(신비 +80)

  • 신비 AR = 60 + (60×0.69×0.03) = 61 → 합계 649
